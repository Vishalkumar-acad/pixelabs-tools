What this page tracks

PixelAbs Tools runs entirely in your browser — image compression, PDF merge, QR codes and every other local tool work offline and never touch a server. Only a few optional heavy operations (like large video-to-GIF conversions) can use a cloud mode, and that is what this page monitors.

If a cloud service shows downtime here, the site still works — only the optional cloud mode of that one operation is affected, and it switches back to local processing automatically.
