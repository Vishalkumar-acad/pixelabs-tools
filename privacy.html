🔒 Privacy Policy

Effective date: 26 September 2026 · Applies to tools.pixelabs.in

The short version

PixelAbs Tools has no user accounts, no sign-up, no cookies, no analytics, no ads and no third-party trackers. Your files are processed on your own device, inside your browser, by default — they never leave your device unless you explicitly choose the optional Cloud mode in a tool that offers it. We do not build profiles of visitors and we have nothing to sell.

What we do not collect

  • No accounts or sign-ups — we never ask for your name, email or any identifier to use the tools.
  • No cookies — the site sets no tracking cookies of any kind.
  • No analytics or ads — there is no Google Analytics, ad network, fingerprinting or social pixel on this site.
  • No file retention — files are never saved, backed up, or shared by us, in Local or Cloud mode (see below).
  • No IP address storage by the application — the app itself does not record your IP address or store it anywhere.

Where your files are processed

Local mode (default in every tool): all processing (compression, conversion, merging, splitting, formatting) runs entirely inside your browser using JavaScript and WebAssembly. Your files are not uploaded anywhere. The tools also work offline after your first visit.

Cloud mode (optional, off by default): a few tools offer an opt-in Cloud mode that can produce better results (for example Ghostscript-based PDF compression, or HEIC photo conversion on devices that cannot open HEIC). When you choose Cloud mode:

  • Your file is uploaded over HTTPS to our processing endpoint on our own domain, which forwards it to a small processing server.
  • The server processes the file in memory only, returns the result, and discards it immediately. Nothing is written to disk, nothing is queued, nothing is logged about your file.
  • Files pass through our edge network as a stream and are never stored there either.
  • If the server is unavailable, the tool automatically falls back to processing on your device.

If you do not want a particular file transmitted anywhere at all, simply keep the mode set to Local — that is always the default.

Anonymous technical reports

If a page fails to load, the site sends one small, anonymous report so we can fix problems. It contains only:

  • the error message (truncated to 200 characters),
  • the page path (for example /tools/qr-code.html),
  • a timestamp.

Reports never include your IP address (as stored by the app), file names, file contents, or anything that identifies you. These are the only data the site ever sends home.

Information stored on your device

The site uses your browser's localStorage to remember your theme preference (dark or light) and to keep a local counter of how many bytes the tools have saved you. This data stays on your device and is never transmitted to us or anyone else. Clearing your browser data removes it.

Third-party services

  • Cloudflare hosts this website and serves its pages. Their handling of network traffic is governed by Cloudflare's own privacy policy.
  • Render.com runs the small processing server used by optional Cloud mode. Files sent there are processed in memory and deleted immediately, as described above.
  • An uptime monitoring service periodically checks a public health endpoint. It never sees or sends any user data.

Children's privacy

The site is a general-purpose utility and is safe for all ages. Since we collect no personal information at all, no personal information of children is collected.

Changes to this policy

If we change this policy we will update the date at the top of this page. Because the site collects essentially nothing, changes will be rare.
